# ディープラーニングをスクラッチから実装

## 概要
本プロジェクトは研究の一環として、深層学習技術をスクラッチから実装することを目的としている。  
書籍「ゼロから作るディープラーニング」シリーズ（オライリー・ジャパン）をベースに、NumPyによる基礎実装から、抽象フレームワークの構築まで体系的に学習・実装を行った。

---

## 特徴

- 数式からアルゴリズムまでを一貫して**NumPyで再構成**
- 実装を通じて、**誤差逆伝播・自動微分・Attention・演算グラフ**などの動作原理を体得


---

## リポジトリ構成

### part1：[./part1](./part1)
